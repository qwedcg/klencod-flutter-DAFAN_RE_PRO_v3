# DAFAN RE PRO v3.0

مشروع Android مبني على v2 مع إضافة أولية لأدوات Lua.

## إضافات Lua في v3
- تحليل أولي لملفات Lua.
- التعرف على ترويسة Lua binary chunk وتخمين رقم الإصدار من بايت الإصدار المعروف.
- محرر نصي لملفات Lua النصية UTF-8 حتى 2MB لتقليل مخاطر الذاكرة على الهاتف.
- حفظ المصدر المعدّل كملف مستقل `_edited.lua`.
- عدم الكتابة فوق الملف الأصلي.

## حدود Lua الحالية
- لا يوجد حتى الآن Decompiler كامل لبايت كود Lua.
- لا يوجد تجميع إلى Bytecode في هذا الإصدار؛ زر إعادة البناء يحفظ ملف المصدر النصي المعدّل فقط.
- ملفات Lua المشفرة أو المغلفة بتنسيق خاص تحتاج تحديد خوارزمية التغليف/التشفير، والمفتاح إن وجد.
- Lua forks أو bytecode مخصص للعبة قد يختلف عن Lua القياسي حتى لو ظهرت ترويسة مشابهة.
- للحفاظ على التوافق، يجب توفير/دمج luac أو compiler مبني لنفس إصدار Lua والـ fork والمعمارية المستهدفة، ثم اختبار الناتج داخل بيئة يملك المستخدم حق تعديلها.

## الميزات الأساسية الموروثة من v2
- تحليل ترويسة الملف.
- استخراج أقسام ELF/SO الفعلية المتاحة.
- استخراج ZIP/APK/JAR/OBB.
- استخراج ASCII strings.
- فحص تواقيع موارد مضمّنة وتسجيل offsets.
- قراءة متدفقة للملفات الكبيرة في وظائف الاستخراج.
